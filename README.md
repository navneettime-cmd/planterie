# Planterie Sunday Terrarium Workshop: Landing Page

A single-page, mobile-first landing page for Planterie's Sunday Terrarium Workshop in Panchsheel Park, New Delhi. Its one goal is to get the visitor to book a seat.

Made by Navneet Sarsar for Kraftshala's Marketing Launchpad Programme (MLP 52), AI Led Marketing module.

- **Live (Lovable build):** https://planterie-navneet-m52ft.lovable.app

## What's on the page

- A hero with the next workshop date (it updates itself to the coming Sunday) and a Book Now button.
- How the morning goes, what's included, pricing, who it's for, reviews, the café, and an FAQ.
- A booking pop-up with Sunday and seat selection, form checks, a live booking-fee total and an on-screen confirmation.
- A sticky Book Now bar on mobile that shows whenever the hero button is out of view.
- No outbound links. The page has one action only.

## Deploy

**GitHub Pages**

1. Upload these files to a public repository, with `index.html` at the top level.
2. Go to Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, and save.
3. The site link appears on the same page after a minute or two.

**Vercel**

1. Sign in at vercel.com and choose "Add New", then "Project".
2. Import this repository. No settings are needed, since it's a static site.
